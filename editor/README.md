# ReForge Editor

Run these commands from the editor folder in Kiro:

```powershell
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
```

Open the local URL printed by Vite. The sample game loads on startup. Use **Open game** to load another contract-shaped JSON file.

Run `pnpm test` to check the document loader and `pnpm build` to type-check the editor and build it for the browser.
