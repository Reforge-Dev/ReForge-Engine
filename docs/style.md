# Style

ReForge is a haunted terminal, not a neon dashboard.

## Color

| Token | Hex | Use |
|---|---|---|
| ink | #0c0d0b | Page background |
| bone | #e7e4d8 | Body text |
| ember | #e07a3d | Alerts, breach, primary button |
| ghost | #8aa384 | Healthy nodes, success |
| line | #2a2c26 | Borders and the graph links |
| danger | #c4493a | Loss and wrong response |

## Type

Do not bundle a font yet. Use a plain sans for labels and a monospace face for logs. If a font file is added later, record its license in `cyberops/assets/CREDITS.md` first.

## Shape

Panels are flat rectangles with a 1px line border. No gradients, no glow, no copyrighted icons. Nodes are simple shapes plus a label. Status colors: ghost healthy, ember haunted, bone working, danger lost.
